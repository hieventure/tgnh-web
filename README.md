# Thế Giới Nước Hoa — frontend tĩnh

Mở `index.html` để xem bản bàn giao. CSS, JavaScript và ảnh nằm trong `assets/`; trang có thể mở trực tiếp bằng `file://` mà không cần build hay server.

Dữ liệu sản phẩm hiện là dữ liệu mẫu. Các link danh mục và sản phẩm giữ đường dẫn của website để client ánh xạ khi tích hợp; chúng không mở trang con khi xem bằng `file://`. Font Roboto cần kết nối mạng để tải từ Google Fonts.
